# v0.6.1 Hardening Implementation Plan

**Goal:** Release a conservative v0.6.1 with current official Actions and source-independent capability package verification.

**Architecture:** Keep runtime contracts and declarative resources frozen. Share one isolated wheel smoke script between main CI, release CI and local validation.

**Constraints:** Exactly seven roles; no executable extensions, dependency solver, inheritance, hidden activation, protected overrides or lifecycle/recovery weakening. Do not modify the personal managed install. Research documents remain historical.

- [x] Run Python 3.9 full tests, all seven repository validators, compile/syntax/diff checks, release-tag validation, Windows offline acceptance, build and isolated wheel smoke. Obtain independent read-only release review.
