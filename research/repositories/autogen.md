# microsoft/autogen

Source: https://github.com/microsoft/autogen

Status note: the upstream project is in maintenance mode and directs new users to Microsoft Agent Framework.

## Historical value

- **ADAPT — layered runtime:** separate low-level message/event runtime from higher-level agent-chat abstractions and provider extensions.
- **ADAPT — benchmark tooling:** orchestration choices should be measurable.
- **REJECT — historical group-chat patterns as a default:** unconstrained conversational coordination can add tokens without improving outcomes.

## Project consequence

AutoGen is retained as a historical architecture source, not as the reference implementation for new design decisions. Current Microsoft Agent Framework guidance takes precedence when the two diverge.
