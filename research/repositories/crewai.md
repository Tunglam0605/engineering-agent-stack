# crewAIInc/crewAI

Source: https://github.com/crewAIInc/crewAI

## Focus

Role-based autonomous agent collaboration through Crews plus deterministic event-driven orchestration through Flows.

## Useful patterns

- **ADOPT — autonomy/control separation:** use deterministic flows for coordination and bounded agent autonomy inside tasks.
- **ADAPT — role-based collaboration:** specialist roles can improve difficult work when routing evidence supports them.
- **ADAPT — structured task outputs:** assignments should define expected output and dependencies.
- **REJECT — autonomous delegation as a universal default:** not every engineering task benefits from a crew.

## Project consequence

Our orchestrator remains the control plane. Agents are workers with contracts, not a self-organizing organization unless an eval proves that topology useful.
