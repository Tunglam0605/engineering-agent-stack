# awslabs/cli-agent-orchestrator

Source: https://github.com/awslabs/cli-agent-orchestrator

## Focus

CLI-oriented orchestration for coordinating multiple coding agents and execution lanes.

## Research questions

This source is included to study:

- task decomposition and dependency representation
- parallel execution boundaries
- workspace/worktree isolation
- failure recovery and aggregation
- orchestration overhead relative to direct execution
