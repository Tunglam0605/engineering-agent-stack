# Core Agents

Production role definitions will be introduced in v0.1 after the canonical schema and research matrix stabilize.

Planned core roles:

- `scout`
- `researcher`
- `implementer`
- `debugger`
- `test-engineer`
- `reviewer`
- `architect`

Do not add role files merely to increase catalog size. Each role must justify a distinct responsibility boundary and conform to `schemas/agent-contract.yaml`.
