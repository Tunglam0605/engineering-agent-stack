# Specialist Agents

Specialists are intentionally deferred until the generic core has benchmark evidence.

Candidate engineering specialists:

- Embedded Firmware Engineer
- STM32 Debugger
- Realtime Systems Reviewer
- ROS 2 Engineer
- Robotics Integration Engineer
- Developer Tooling Engineer

Acceptance criterion: a specialist must produce a repeatable quality or efficiency improvement over the core role + skill approach that justifies extra routing and maintenance complexity.
